# 📖 About LearnHUB

**LearnHUB** is a MERN Stack-based learning platform designed to provide an engaging environment for students and teachers.

The platform focuses on delivering a modern learning experience through video-based content, role-based dashboards, and a premium **Glassmorphism UI**.

The repository contains:

- 💻 Project source code
- 📄 Project documentation
- 🎥 Video demonstrations
- 🎨 Design diagrams
- ⚙️ Setup instructions

---

# 🚀 Quick Start

If you want to run the LearnHUB application locally, follow the steps below from the root directory.

## 1️⃣ Start the Backend

```bash
cd "Project Files/backend"
npm install
npm start
```

---

## 2️⃣ Start the Frontend

```bash
cd "Project Files/frontend"
npm install
npm run dev
```

---
